## 📝 Descrição do Projeto
O **QR Craft** é uma plataforma inovadora para criação de QR Codes que combina precisão técnica com uma estética artística única (estilo Sketch/Watercolor). O sistema permite gerar códigos industriais, mas com um toque visual refinado, ideal para marcas que buscam se destacar.
 
O dashboard oferece ferramentas para criação de QR Codes **Dinâmicos** e **Estáticos**, integrando templates inteligentes para WiFi e WhatsApp com logos centralizados automaticamente. A plataforma gerencia todo o ciclo de vida do código, desde o design até o rastreamento via redirecionamento dinâmico.

## 🚀 Tecnologias Utilizadas
* **Frontend:** React 18 + TypeScript + Vite
* **Estilização:** Tailwind CSS (Arquitetura Utilitária) + Shadcn UI
* **Backend & Auth:** Firebase (Authentication & Firestore)
* **Motor Gráfico:** qr-code-styling (Rendering via Canvas/SVG)
* **Animações:** Framer Motion (Transições e micro-interações fluidas)
 
## 📊 Resultados e Funcionalidades
O projeto foi estruturado para garantir máxima conversão e facilidade de uso:
* **Templates Inteligentes:** Configurações otimizadas para WhatsApp e WiFi com inserção automática de logotipos oficiais para reconhecimento imediato.
* **Gestão Dinâmica:** Sistema de links redirecionáveis que permite alterar o destino do QR Code sem precisar mudar a imagem impressa.
* **Modo de Edição Pro:** Interface dedicada que separa a criação da manutenção, garantindo que usuários editem seus códigos sem gerar duplicatas desnecessárias.
* **Estética Diferenciada:** Temas exclusivos (Sketch, Ink, Marker) que fogem do padrão quadrado genérico do mercado.

## 🔧 Como Executar
1. Clone o repositório.
2. Certifique-se de configurar o arquivo `firebase-applet-config.json` com suas chaves.
3. Instale as dependências: `npm install`.
4. Execute o servidor de desenvolvimento: `npm run dev`.
