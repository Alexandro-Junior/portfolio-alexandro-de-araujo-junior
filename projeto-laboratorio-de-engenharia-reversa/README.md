## 📝 Descrição do Projeto
O **QR Code Styling** é uma ferramenta de design avançada para a criação e personalização de códigos QR. O sistema permite que usuários transformem códigos estáticos em ativos de marca visualmente atraentes, integrando logotipos personalizados, gradientes complexos e diversos estilos geométricos para os módulos e cantos do código.

Inspirado pela biblioteca original `qr-code-styling`, este dashboard oferece uma interface em tempo real onde cada modificação — desde a rotação do gradiente até a margem da imagem central — é renderizada instantaneamente, proporcionando um fluxo de trabalho intuitivo para designers e desenvolvedores.

## 🚀 Tecnologias Utilizadas
* **Frontend:** React 19 + TypeScript + Vite
* **Estilização:** Tailwind CSS v4 (Arquitetura Utilitária)
* **Componentes:** shadcn/ui (Baseado em Radix UI para acessibilidade)
* **Core Engine:** QR Code Styling JS Library
* **Ícones:** Lucide React
* **Animações:** Motion (Micro-interações e transições fluidas)

## 📊 Resultados e Funcionalidades
O projeto foi estruturado para oferecer total controle sobre a estética do QR Code:
* **Customização Multi-Camadas:** Ajuste individual dos estilos dos pontos (Dots), quadrados dos cantos (Corners Square) e pontos internos dos cantos (Corners Dot).
* **Motor de Cores Avançado:** Suporte nativo para cores sólidas e gradientes lineares/radiais com controle total de rotação.
* **Integração de Branding:** Upload e ajuste de imagens centrais com opção para esconder pontos de fundo para garantir legibilidade.
* **Exportação Flexível:** Download imediato em formatos vetoriais (SVG) e rasterizados (PNG, JPEG, WEBP).
* **Persistência de Dados:** Configurações exportáveis via JSON para reutilização futura de presets.

## 🔧 Como Executar
1. Clone o repositório.
2. Instale as dependências: `npm install`.
3. Certifique-se de que os componentes shadcn foram inicializados corretamente.
4. Execute o servidor de desenvolvimento: `npm run dev`.
